# ImpactHub — Nonprofit Digital Engagement Platform

[![impacthub homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/impacthub-homepage.jpg)](https://impacthub-knowedge.infinityfreeapp.com/)

**[Visit the live website](https://impacthub-knowedge.infinityfreeapp.com/)**

Independent WordPress portfolio project by KnowEdge Business Development Services Ltd. Includes editable campaigns, programmes and impact stories; responsive navigation, giving and volunteer preview workflows, and sample campaign progress displays. No real charitable donations, volunteer registration, or payment processing.

Install by zipping the theme/impacthub directory, uploading it in WordPress Appearance → Themes, and activating it. Example data is created on first activation.
